## Overview

A command-line number guessing game written in Python. The computer randomly selects a number between 1 and 10, and the user repeatedly guesses until they find the correct number. The program provides feedback to help the user determine whether each guess is too high or too low.

## Features

- Generates a random number between 1 and 10.
- Accepts guesses from the user.
- Indicates whether a guess is too high or too low.
- Checks whether the input contains a numeric value.
- Counts the number of valid guesses.
- Congratulates the user when the correct number is guessed.

## Technologies

- Python `random` module

## How to Run

1. Ensure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project directory.
4. Run:

```bash
python main.py
```

Depending on your system, you may need to use `python3 main.py`.
